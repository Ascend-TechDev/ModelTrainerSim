# 待确认事项

已实现的基础场景、层耗时、非专家 FSDP、E-FSDP、E-DP、Engram 及 EP 前向分析输入完整，以下项目按影响范围补齐。前向预取与 SU/SO 重叠假设已确定，见 [非专家 FSDP](tasks/non_expert_fsdp.md#前向掩盖假设)。

| 影响范围 | 缺少的条件 | 对当前结果的影响 |
|---|---|---|
| 物理链路规格 | 网络有效利用率、端口共享、收敛比、延迟、并发争用 | 当前输出单卡有效带宽；掩盖率扩展直接使用给定链路档位，不额外折减 |
| EP 实际调度扩展 | 实际 token 分块、流水启动/排空、GEMM 与通信的资源争用 | [当前实现](tasks/ep.md)已完成中间维×EP Size×三种精度的 189 场景扫描；GEMM 95%、All2All 70%，按理想层内稳态窗口计算，扩展项不影响当前独立结果 |
| EP 反向 | 激活梯度通信精度、dX/dW 的计算与通信窗口 | 本轮已确认只分析前向；反向另行建模，不直接套用 FP32 参数梯度或两倍前向时间 |
| E-DP 扩展 | 启用梯度累积时的同步频次与调度、与其他通信的联合争用 | [当前实现](tasks/expert_dp.md)按每次 micro-batch 反向同步一次、整层反向稳态窗口计算；不影响现有三种 E-DP 独立结果 |
| Engram 扩展 | 实际预取/梯度回传调度、缓存/去重策略、随机查表及往返时延 | [当前方法](tasks/engram.md)仅分析所选最大MoE层的一张表，均衡访问、无缓存/去重；前向和反向均采用1/5/10/15/20层完整预算，前向开始前也有足够可掩盖计算，不按层号截断、不考虑多表争用；不阻塞当前计算 |
| 整步/训练目标 | 梯度累积、全局 batch、目标 token 数、完成时限 | 不影响当前单层基线；影响整步与集群目标评估 |

反向通信尾部按本阶段约定暂不纳入。上述项目明确后，只更新对应任务、输入和校验项。
