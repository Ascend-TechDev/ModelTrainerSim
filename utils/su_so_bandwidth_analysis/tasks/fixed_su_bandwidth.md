# 固定 SU Size、HBM、精度的全因子联合寻优

沿用 [SU/SO 联合建模](joint_bandwidth.md) 的带宽、分层通信、边界和档位判定。外层固定 SU Size、HBM、精度三个因子，内层重新扫描全部集群规模及并行组合，不跨固定规格择优。

本次按模型名称选择 6 个 10T/20T 模型：DeepSeek Next-10T、Next-20T，Hunyuan 10T，Kimi 10T Wide-v2、20T，GLM-10T。SU Size 分别固定为 576、1152；总卡数仍为 `N=SU Size×k`，k 沿用原扫描值，`N<200000`。

## 外层场景因子

| 因子 | 固定取值 |
|---|---|
| SU Size | 576、1152 |
| 单卡 HBM | 192、288 GB |
| 精度 | FP8、BF16、DeepEP |

每模型 `2×2×3=12` 个独立场景，6模型共72组。场景编码SC01～SC12按SU、HBM、精度顺序排列；模型ID与场景编码共同组成唯一键。HBM规格是固定输入，不再增加“可选HBM”组。

## 内层搜索

在每个固定场景中，k遍历原集合 `[1,2,4,8,16,32,64,128]`，约束 `N=SU Size×k<200000`。EP遍历原候选，要求EP整除SU和专家数且EP<SU；E-FSDP遍历N/EP的全部正整数约数，E-DP=N/(EP×E-FSDP)，FSDP=N。按固定精度及HBM容量执行95%容量检查。

SU=576时可用EP候选为8/16/32/64，SU=1152时为8/16/32/64/128，仍须满足模型专家数约束。所有合法的N和并行组合都参与比较，不能只筛选之前的最优结果。原基础场景编号保留，另输出每组HBM合法候选数。

每组先求精确Pareto可行边界，再检查既定SU六档、SO两档。保留所有互不支配的最低可行预算组合；代表配置只从同时满足预算的Pareto边界策略中选择，不能将被另一方案在两侧带宽上支配的配置称为联合最优。边界同点或有多个可行边界候选时，依次优先总卡数小、SU Size小、HBM小、EP小、E-FSDP小、E-DP小、场景ID小；完整边界仍保留全部取舍。

这是“带宽优先、卡数其次”的寻优。此前全量联合表采用“档位可行后优先卡数少”的代表规则，保留作历史分析；本次固定三因子输出使用更严格的Pareto候选。当前层内和层间掩盖假设、EP 70%利用率及其他任务口径均不改变。

## 输出

刷新同一份产物：[SU_SO联合带宽配置_10T20T_SU576_1152.xlsx](../../../results/SU_SO联合带宽配置_10T20T_SU576_1152.xlsx)。

- 场景最优配置：每个固定场景的最低可行带宽组合、候选数、总卡数、SU域数、完整并行策略、HBM占用及实际SU/SO需求；多个最低组合均保留。原25列后追加下述10项分域带宽，共35列。
- 场景因子：12个固定组合。
- 模型边界、连续可行边界、档位可行性：分别保留独立下界、完整Pareto边界及72×12个预算判定。
- 通信分项明细：每个所选策略展开9个通信阶段，各记录单卡SU/SO带宽；当前72个配置共648行、18列。
- 说明：口径及执行方式。实际需求与带宽档位分列，不能将档位内代表策略称为唯一的连续带宽最优点。

### 通信域带宽

五类通信域分别追加 `{domain}_SU_required_GBps`、`{domain}_SO_required_GBps`，单位GB/s。数值来自本行所选策略，不对各通信域重新寻优。

| domain | 汇总所含阶段 | 分域需求 |
|---|---|---|
| `FSDP` | 非专家前向All-Gather、反向Reduce-Scatter | 两阶段分别在SU、SO上取最大值 |
| `E_FSDP` | 专家前向All-Gather、反向Reduce-Scatter | 两阶段分别在SU、SO上取最大值 |
| `E_DP` | 反向All-Reduce | 对应SU、SO需求 |
| `EP` | 前向dispatch、combine | SU取两阶段最大值；SO为0 |
| `Engram` | 前向查表、反向梯度 | 两阶段分别在SU、SO上取最大值 |

联合SU/SO需求仍分别为五类通信域需求的最大值，不求和。EP沿用有效需求除以70%的链路需求口径，其他通信域不额外折减；Engram采用最短前向1层、反向1层窗口，只考虑所选最大MoE层的表。

明细页记录模型、固定因子、源场景ID、N及并行分组、SU/SO预算、通信域、阶段和两侧需求。以模型ID、因子场景ID及预算组合关联主表；可同时保留多个最低预算组合。无对应通信记0；EP反向未建模，不生成对应记录。无可行策略时主表分域值为“—”，不生成明细。

```bash
python3 scripts/analyze_su_so_bandwidth.py \
  --model-ids dsv41next10t dsv41next20t hy4_10t kimi_10t_wide_v2 kimi_20t glm_10t \
  --su-sizes 576 1152 \
  --hbm-sizes 192 288 \
  --output results/SU_SO联合带宽配置_10T20T_SU576_1152.xlsx
```

只读核查使用相同命令追加 `--check`。未指定筛选条件时继续计算原全量任务；有筛选条件但未指定输出时，默认输出 `SU_SO联合带宽配置_筛选.xlsx`，避免覆盖原全量结果。

核查每模型12个场景完整且不重复，所选SU/HBM/精度与固定因子一致，各场景候选独立；档位可行性与全部受限候选一致，策略满足HBM、分组守恒及两侧预算。分项明细必须匹配所选配置，各阶段最大值等于对应域需求、各域最大值等于原联合需求。原全量结果执行只读回归核查。
