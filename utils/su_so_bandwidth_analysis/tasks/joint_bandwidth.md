# SU/SO 联合带宽与并行配置

对每个模型，分别求 SU、SO 需求下界，再向上探索可由同一套并行策略满足的带宽组合。独立输出 [SU_SO联合带宽配置.xlsx](../../../results/SU_SO联合带宽配置.xlsx)。

## 输入与约束

沿用 [模型输入](../model_inputs.md)、[场景输入](../scenario_inputs.md)、HBM 约束及[最小 SU 任务的各通信项口径](min_su_bandwidth.md)。仅使用分层 FSDP/E-FSDP/E-DP，EP 为 SU 内前向 All2All，Engram 为所选层按需查表。

模型×FP8/BF16/DeepEP 分别分析；HBM 可选 192/288 GB，同时保留固定两种规格的结果。SU Size、总卡数、EP、E-FSDP、E-DP 继续在原扫描范围内变化。`FSDP=N=EP×E-FSDP×E-DP`，EP 完整位于 SU 内。

EP有效需求按70%利用率折算到链路档位，其他任务沿用原档位口径；单位GB/s。每条链路取各已建模通信项需求的最大值，不叠加争用。Engram使用最短前向1层、反向1层窗口；EP反向未建模。

## 两个独立下界

对 HBM 合法配置集合 X，令 u(x)、o(x) 为同一配置的 SU、SO 需求：

```text
u(x) = max(该配置各通信项的SU需求)
o(x) = max(该配置各通信项的SO需求)
u_min = min_{x∈X} u(x)
o_min = min_{x∈X} o(x)
```

记录 u_min、o_min，以及 SU 最小时能达到的最小 SO、SO 最小时能达到的最小 SU。独立下界不一定能同时取得，不能拼接两套配置。扫描允许 k=1，单个 SU 可容纳模型时，SO 下界可以为 0。

## 同时可行的判定

给定 SU、SO 档位 U、O，要求存在同一个 x：

```text
HBM(x) ≤ 0.95×HBM容量
u(x) ≤ U
o(x) ≤ O
```

沿用当前各分项独立掩盖模型，该条件保证已建模分项分别满足掩盖窗口；不表示加入共享链路竞争后仍能完全掩盖。

## 从下界逐步探索

1. 若 `(u_min,o_min)` 存在可行配置，直接记录可同时达到两个下界。
2. 否则，按候选 u(x) 升序扫描，记录 SO 能达到的新低点，即：

   `o_best(U)=min{o(x) | x∈X 且 u(x)≤U}`。

3. 保留不能同时降低 SU、SO 的点及对应策略：不存在另一点两项都不大于它、且至少一项更小。这些点组成连续可行边界（Pareto 边界）。需求值不取整，不自行添加硬件档位。
4. 检查既定 `SU=[400,600,800,1000,1200,1600]`、`SO=[100,200]` 的全部 12 个组合。各组合标记是否可行，并绑定一套同时满足条件的策略。
5. 在可行档位中保留所有没有更低可行预算组合的点。例如 `(800,200)` 和 `(1000,100)` 可同时保留。未给定成本权重时，不指定唯一的带宽组合，也不依赖先加 SU 还是先加 SO 的遍历顺序。

若当前档位内无解，明确标记，并保留连续边界上的更高需求；不能因某条搜索路径失败而判定整个模型无解。SO=0 只表示无跨域需求，不自动增加硬件档位。

相同边界点或给定预算内有多套策略时，依次选择总卡数较少、SU Size 较小、HBM 较小、EP 较小、E-FSDP 较小、E-DP 较小、场景 ID 较小的代表配置。不存在相互支配的预算组合均保留。

## 输出与执行

| 页签 | 内容 |
|---|---|
| 模型边界 | 各分组的独立下界、交叉需求、能否同时达到、边界点数和可行档位数 |
| 连续可行边界 | 精确 SU/SO 需求对、同一套完整并行策略、HBM 占用和两侧瓶颈 |
| 档位可行性 | 每个分组的全部 12 档组合；可行标记及代表策略 |
| 最低可行档位 | 全部未被更低预算组合支配的可行档位及策略；无档位解时明确标记 |
| 说明 | 输入口径、边界定义、同值择优和执行方式 |

当前每模型/精度含“HBM 可选、固定 192、固定 288”三组。预算列与实际需求列分开记录；DeepEP 的场景 ID 对应原 FP8 基础行。

```bash
python3 scripts/analyze_su_so_bandwidth.py
python3 scripts/analyze_su_so_bandwidth.py --check
```

计算见 [joint_bandwidth.py](../../../scripts/su_so_modeling/joint_bandwidth.py)，[独立入口](../../../scripts/analyze_su_so_bandwidth.py)。与单 SU 优化共用 [配置指标](../../../scripts/su_so_modeling/configuration_metrics.py)，不改写已有结果。

核查全量枚举、边界单调性和完整性、档位可行性与全量候选一致性，以及同一个配置同时满足两条链路约束。代表配置用原始通信量/精确时间独立复核；测试独立下界不可拼接、重复及被支配点剔除、多个最低预算组合、零 SO 和阈值等号。
